# Original experiments

`original-root/` preserves the original local stock-prediction experiment files. Its Python data window was January–September 2025.

`github-root/` preserves the files that used to live at the GitHub repository root before the dashboard rework.

`original-project/` preserves the former stock-price-prediction-model directory, including its README and longer-window script (2010–2025). Its nested Git metadata was removed so it behaves like a normal archive folder.

These files are historical reference and are not used by the dashboard. A few archived R/session files are kept only because they were part of the original experiment. The reported model performance should be treated as a learning artifact, not proof of real forecasting accuracy.
